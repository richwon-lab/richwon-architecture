# 명판 업무 기본 개념

문서 ID: BUS-NAMEPLATE · 상태: 검토 중 · 내용 책임: 제품 책임자 · 개정: 0.1 · 2026-11-22

명판은 장비, 설비, 부품 등을 식별하거나 필요한 정보를 표시하는 제작물이다. 리치원컴퍼니의 주문형 명판은 발주마다 문구, 규격, 재질, 색상, 가공 방식, 수량이 달라질 수 있다. 같은 크기의 명판도 홀 위치, 문구 영역, 고객별 제작 기준이 다르면 별도 디자인으로 다룬다.

## 발주와 제작 단위

| 용어 | 의미 |
| --- | --- |
| 발주 | 고객이 요청한 작업 묶음. 한 발주에 여러 디자인·재질·가공 방식이 포함될 수 있다. |
| 고객 프로젝트 | 필요한 경우 고객의 주문·검색·포장을 구분하는 정보. |
| 디자인 | 외곽, 홀, 테두리, 장식, 텍스트 영역, 글자 스타일 등 명판의 구성. |
| 디자인별 작업 | 한 발주에서 같은 디자인을 사용하는 명판 항목의 묶음. |
| 명판 항목 | 한 디자인에 적용할 문구와 생산 수량을 가진 작업 항목. 같은 문구가 여러 항목에 들어갈 수 있다. |
| 생산 수량 | 실제로 제작할 개수. 입력 행 수나 도안 파일에 배치된 도형 수와 다를 수 있다. |

## 문구, 도안, 원판

- **명판 문구의 정확성** — 제작할 명판의 문구는 고객이 확인한 원문과 일치해야 한다. 문자·기호·공백·대소문자를 임의로 바꾸거나 누락하면 안 된다. 오타가 의심되면 고객에게 확인한다. 줄바꿈이나 글자 폭 조정은 문구의 배치를 바꾸는 작업이다. 자동화에서 이 원칙을 확인하는 방법은 [DFT-001 인수 기준 초안](../requirements/design-automation.md)을 참조한다.
- **텍스트 영역과 줄** — 제목·번호·본문처럼 명판에서 독립적으로 배치하는 공간이 텍스트 영역이다. 하나의 영역에 여러 줄이 들어갈 수 있다. 예비용 명판이나 일부 영역은 의도적으로 비워 둘 수 있다.
- **도안과 원판 배치** — 도안은 제작할 명판의 형상과 문구 배치를 담는다. 원판 배치는 실제 자재 위에 여러 명판을 배열하는 일이다. 같은 자재를 쓰는 여러 발주를 한 원판에 배치하기도 하므로, 각각 어느 발주에 속하는지 구분해야 한다.

## 작업 자료

| 자료 | 업무에서 쓰는 곳 |
| --- | --- |
| 발주 원본 | 고객이 보낸 문구·규격·수량과 특이 조건을 확인하는 기준 자료. |
| 작업지시서 | 담당자에게 작업 조건과 도안 파일 등 필요한 정보를 전달하는 자료. |
| DXF | 기존 R-edit에서 만든 도안을 Type3로 가져오는 데 사용해 온 교환 파일. |
| VND | Type3에서 도안을 저장하는 파일. Type3에서 마무리한 생산용 도안은 가져온 DXF와 내용이 달라질 수 있다. |
| NC 파일 | 가공 장비가 사용할 작업 경로를 담은 파일. 도안과 작업지시서는 사람 간 자료 인계에, NC 파일은 장비로의 가공 데이터 전송에 쓰인다. |

재주문이나 교체품은 과거 제품과 외형이나 글자 배치를 맞춰야 하는 경우가 있다. 이때 당시 제작 결과와 지금 적용할 고객 기준을 구분한다.

작업 순서와 현장 확인 사항은 [현재 업무 흐름](current-workflow.md)과 [대표 업무와 예외](scenarios.md)에서 확인한다. 업무 단위와 도구의 근거는 업무소프트웨어 요구사항 정의서 v0.7 2~3·8·10절, 핵심요구사항 설계검토 v0.13 34절, 현재 업무 흐름의 생산 업무 기록을 참고한다.
