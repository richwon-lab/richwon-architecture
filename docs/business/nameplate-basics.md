# 명판 업무 기본 개념

문서 ID: BUS-NAMEPLATE · 상태: 검토 중 · 내용 책임: 제품 책임자 · 개정: 0.1 · 2026-11-22

이 문서는 명판 업무에 처음 참여하는 담당자가 발주와 제작 단위, 문구와 도안, 작업 자료의 뜻을 파악하는 데 쓰인다.

명판은 장비나 부품을 식별하고 필요한 정보를 표시하는 판이다. 주문에 따라 문구·치수·재질·색상·가공 방식·수량이 달라질 수 있다. 같은 크기의 명판이라도 구멍 위치나 글자가 들어갈 영역, 고객별 제작 기준이 다르면 기존 도안을 그대로 사용할 수 있는지 확인해야 한다.

## 발주와 제작 단위

한 발주에 여러 도안이 포함될 수 있고, 같은 도안으로도 문구와 제작 수량이 다른 명판을 만든다. 아래의 ‘도안별 작업’과 ‘명판 항목’은 이 관계를 설명하기 위한 문서 용어다.

| 용어 | 의미 |
| --- | --- |
| 발주 | 고객이 요청한 제작 건. 한 건에 여러 도안·재질·가공 방식이 포함될 수 있다. |
| 도안 | 명판의 외곽, 구멍 위치, 테두리, 글자가 들어갈 영역과 글자 모양 등을 정한 구성. |
| 도안별 작업 | 한 발주에서 같은 도안을 사용하는 명판 항목의 묶음. |
| 명판 항목 | 발주에서 한 도안에 적용할 문구와 제작 개수를 함께 보는 단위. 같은 문구가 여러 항목에 들어갈 수 있다. |
| 생산 수량 | 실제로 제작할 명판의 개수. Excel 행 수나 도안 파일에 배치한 개수와 다를 수 있다. |

고객 프로젝트는 필요에 따라 발주 검색이나 포장에 쓰는 구분 정보다.

## 문구, 도안, 원판

- **문구와 문구 배치** — 문구는 명판에 들어갈 내용이다. 문자·기호·공백·대소문자는 고객이 확인한 원문을 따르며 오타가 의심되면 고객에게 확인한다. 문구 배치는 그 내용을 명판 안의 어디에 놓을지, 어느 지점에서 줄을 바꿀지, 글자 폭을 어떻게 조정할지 정하는 일이다. 자동화에서 원문을 보존하는 기준은 [DFT-001 인수 기준 초안](../requirements/design-automation.md)을 참조한다.
- **텍스트 영역과 줄** — 제목·번호·본문처럼 명판에서 독립적으로 배치하는 공간이 텍스트 영역이다. 하나의 영역에 여러 줄이 들어갈 수 있다. 예비용 명판이나 일부 영역은 의도적으로 비워 둘 수 있다.
- **도안 작업** — 명판의 형상과 문구 배치를 정하고 생산에 넘길 작업 파일을 마무리한다. Excel로 정리한 대량 발주를 기존 R-edit로 처리할 때 DXF의 격자 배치는 도안 작업용이다. CNC 음각 조각에서는 Type Edit에서 마무리한 VND를 생산에 넘긴다.
- **생산에서의 판재 재배치** — 생산 담당자는 VND를 받아 실제 가공할 판재에 맞게 명판을 다시 배치한 뒤 NC 파일을 만든다. 여러 발주의 명판을 한 판재에 놓을 때는 각 명판이 어느 발주에 속하는지 구분한다. 판재 재배치와 NC 생성은 이번 개발 범위에서 제외한다.

## 작업 자료

| 자료 | 언제 준비하는가 | 다음 사용처 |
| --- | --- | --- |
| 발주 원본 | 고객 발주를 메일·전화·팩스·문자·카카오톡 등으로 받는다. | 도안 담당자가 작업지시서와 함께 발주 내용을 보고 문구·규격·수량과 특이 조건을 확인한다. |
| 작업지시서 | 발주를 확인한 뒤 작업 조건을 정리한다. | 도안 담당자가 발주 원본 내용과 함께 참고하고, 생산 담당자가 도안 작업물과 함께 확인한다. |
| Excel | 대량 발주 내용을 표로 정리할 수 있을 때 준비한다. | 기존 R-edit에 입력해 DXF를 만든다. |
| DXF | 기존 R-edit가 Excel 문구를 글자 객체에 넣고 도안을 격자로 배치해 만든다. | 도안 담당자가 Type Edit로 불러와 줄바꿈 등 남은 작업을 마무리한다. |
| 도안 작업물(VND) | CNC 음각 조각에서는 도안 담당자가 Type Edit에서 마무리한 도안을 VND로 저장한다. | 생산 담당자에게 넘긴다. 생산 담당자는 이 파일을 열어 실제 가공할 판재에 맞춰 도안을 다시 배치한다. |
| NC 파일 | 생산 담당자가 판재에 도안을 재배치한 뒤 Type Edit에서 생성한다. | CNC 장비로 넘겨 가공에 사용한다. |

재주문이나 교체품은 과거 제품과 외형이나 글자 배치를 맞춰야 하는 경우가 있다. 이때 당시 제작 결과와 지금 적용할 고객 기준을 구분한다.

작업 순서와 현장 확인 사항은 [현재 업무 흐름](current-workflow.md)과 [대표 업무와 예외](scenarios.md)에서 확인한다. 업무 단위와 도구의 근거는 업무소프트웨어 요구사항 정의서 v0.7 2~3·8·10절, 핵심요구사항 설계검토 v0.13 34절, 현재 업무 흐름의 생산 업무 기록을 참고한다.
