# 명판 도안 자동화 요구 후보

문서 ID: SRS-DRAFTING · 상태: 검토 중 · 내용 책임: 제품 책임자 · 개정: 0.1 · 2026-11-21

기존 R-edit는 문구 배치와 격자 생성을 지원해 왔다. 줄바꿈·자폭 수정, 반복 주문의 일관성, 개인 메모에 의존한 고객 기준이 개선 과제다. 기존 R-edit와 주변 Illustrator·AutoCAD 도구의 현재 기능 및 NC 정렬 개발 자산은 연동 조사에서 확인한다. 업무 기준은 [현재 업무 흐름](../business/current-workflow.md), 판정용 입력은 [대표 업무와 예외](../business/scenarios.md)를 따른다.

> **검토 주석 RV-12:** 아래 요구와 인수 기준은 도안 자동화 범위를 검토하기 위한 후보다. 첫 도입 포함 범위는 RV-05에서, 품질 조건과 과거 설계 승계 범위는 RV-12에서 정한다.

## 설계에서 비교할 사항

- **배치와 편집** — v0.7의 개별 자폭 직접 편집과 v0.13의 수동 전체 개행 후 자동 맞춤은 서로 다른 대안이다. 영역별 기본 크기, 줄별 자폭, 선호 줄 수와 필수 고정 줄 수, 조각과 인쇄의 판정 기준을 사례별로 비교한다. 시험 도안의 치수·자폭·가공 수치를 공통 기본값으로 적용하는 선택은 별도 검토한다.
- **실행과 최신성** — 입력 후 명시적으로 배치하는 방식, 수량 변경 시 재계산 필요 여부, 취소와 늦게 완료된 계산의 판별을 검토한다.
- **데이터와 책임** — 발주·항목·영역의 식별, 고객·도안·이번 작업 기준의 적용 범위, 공통 기준 변경과 일회성 수정의 권한을 검토한다. 생산 합배치에서 주문 소속 유지와 수정본 인계는 업무 범위에 맞춰 설계한다.
- **Type Edit·기술 경계** — 편집 가능한 줄별 DXF TEXT와 미리보기 글자 윤곽을 구분해 검증한다. DXF 버전, 문자·치수 허용 범위, VND 연결 방식은 현장 환경에서 결정한다. Flutter/Dart, 공유 방식·비용 목표, DWG·배송 범위는 현 프로젝트에서 별도로 판단한다. 생산에서 수행하는 판재 재배치와 NC 생성은 이번 개발 범위에서 제외한다.

v0.13의 배치 후보는 선호 줄 수·가독성을 최적화하는 조건과 원문·홀·허용 경계처럼 점수로 상쇄할 수 없는 조건을 구분한다. 영역 내 같은 글자 크기와 줄별 자폭, 소량 작업의 준비 부담, 수동 한 줄 지정 유지 여부를 검토한다. 조각용 커터 경험값은 실제 가공 검증에 사용하고 인쇄에는 별도 기준을 둔다. 초기 점수 절충안과 후속 크기 우선안은 v0.13 24·28·39·44~49절에서 구분해 비교한다.

최종 출력이 고객 공통 기준을 자동 갱신하는지, 고객 내 프로젝트가 달라도 문구 패턴을 재사용하는지, 고객 간 규칙을 어떻게 격리하는지는 별도 설계 선택이다. 새 도안 등록과 공통 기준 변경의 권한도 구분해 검토한다. Type Edit 후편집의 자동 역반영 여부는 DFT-004의 결과 구분과 별도로 결정한다.

v0.13의 배치 후보는 선호 줄 수·가독성을 최적화하는 조건과 원문·홀·허용 경계처럼 점수로 상쇄할 수 없는 조건을 구분한다. 영역 내 같은 글자 크기와 줄별 자폭, 소량 작업의 준비 부담, 수동 한 줄 지정 유지 여부를 검토한다. 조각용 커터 경험값은 실제 가공 검증에 사용하고 인쇄에는 별도 기준을 둔다. 초기 점수 절충안과 후속 크기 우선안은 v0.13 24·28·39·44~49절에서 구분해 비교한다.
